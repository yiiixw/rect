# 015940 水下标定修复报告（2026-09-08）

## 原始标定问题

- 66 采集 / 57 有效，但双目 RMS **22.17 px**、基线塌缩至 **1.9601 cm**（物理值 ≈2.96）
- 原因：第 9/31/36/37 组（按有效组序号）右视图角点被检测器以 **180° 反向起点**返回。
  8×11 内角点网格本身 180° 旋转对称——单目标定无感（等价合法位姿），双目逐点对应全错，
  最小二乘被 4 组坏数据整体拖歪。与 20260907_213528 run 的 #30 污染同一根因。

## 修复过程（全部离线完成，未重新采集）

1. 逐图重投影误差定位 4 组坏图（误差 123~245 px，其余中位 5.9 px）
2. 对 4 组右图角点倒序后误差降至 0.47~0.90 px → 全部找回，57 组零损失
3. 重估单目 dist（固定 K）→ RMS 0.653/0.643 px
4. 重估双目 R/T → **RMS 0.683 px，基线 2.9668 cm**（与玻璃阶段 2.9621 一致）
5. 加入深度规范修正键（见下）生成本 npz

## 深度规范修正（本次新增的算法修复）

固定空气 K 的水下标定输出的是折射**虚拟深度** Z_v = c + Z_真实/1.333（近轴精确，
表现为基线=物理值、RMS 极好、但读数系统性偏小 ~25%）。本 npz 写入：

- `depth_scale = 1.3333`（水的相对折射率）
- `depth_offset_cm = 1.1`（相机光心到玻璃外表面等效空气光程，由本 run 9 个有效样本拟合）

测深端 `stereo_depth_core` 读取后按 **Z_真实 = 1.3333 × (Z_raw − 1.1)** 还原。
